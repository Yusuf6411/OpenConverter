# JPEG 2000

Decoder in `crates/oc-jp2`, wired into the image formats by `crates/oc-image/src/jp2.rs`, the PDF `JPXDecode` filter and the engine's `jp2` format. Read only: `.jp2`, `.j2k` and `.j2c` are inputs.

**Source.** Written from the structure of ITU-T T.800 (ISO/IEC 15444-1) and checked against OpenJPEG; no other decoder's code was used. The spec itself is not free to fetch, so every table in the crate is either defined by a short formula (the MQ probability table, the context labels, the wavelet lifting steps) or was verified against OpenJPEG output rather than assumed.

**What is decoded.** JP2 files (signature, `ihdr`, `colr` with enumerated colour spaces or an ICC profile, `pclr`/`cmap` palettes, `cdef` channel definitions) and raw codestreams.

- Tier 2: packet headers with bit stuffing, tag trees, layers, all five progression orders (LRCP, RLCP, RPCL, PCRL, CPRL), progression order changes (POC), precincts, SOP and EPH markers, tiles and tile-parts, per-tile and per-component coding style overrides.
- Tier 1: the MQ decoder and the three coding passes with every code-block style (selective arithmetic bypass, reset contexts, termination on every pass, vertically causal contexts, predictable termination, segmentation symbols).
- Quantisation: none, scalar derived and scalar expounded; region-of-interest max-shift.
- Wavelets: reversible 5/3 and irreversible 9/7, any number of levels, odd origins.
- Component transforms: RCT and ICT; DC level shift; subsampled components (upsampled by replication); 1 to 16 bit samples, signed or not.
- Output: grey, grey with alpha, RGB, RGBA; CMYK and sYCC are converted to RGB; palette images are expanded; 16-bit output when any component is deeper than 8 bits.

**How it was checked.** `crates/oc-jp2/tests/data` holds streams made with OpenJPEG (through `glymur`) and with ffmpeg's `libopenjpeg` and native encoders, together with what OpenJPEG decodes from them. The test requires an exact match for the reversible path and a difference of at most one level for the 9/7 path (the float rounding of the lifting steps differs). Covered: lossless RGB, all code-block styles together, bypass, termall with vertical causal, tiles with layers and RPCL, precincts with PCRL, CPRL with small code blocks, irreversible, 8-bit and 16-bit grey, RGBA. During development the same comparison ran over several hundred random parameter combinations. The damage test flips bits and truncates the fixtures and requires errors, never panics (`JP2_FUZZ_ROUNDS` sets the number of rounds).

**Not done.** Encoding; JPEG 2000 Part 2 extensions; packed packet headers (`PPM`, `PPT`), which return an unsupported-variant error; Motion JPEG 2000. Progression order changes, region-of-interest shifts and palettes are written from the standard but no fixture exercises them.
